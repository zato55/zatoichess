# ZATO Chess V89 — Sürüm Notları

V89, ZATO Chess'in 1.0 öncesi yayın adayı dondurma sürümüdür.

## Yapılanlar
- Sürüm 89.0.0 olarak sabitlendi.
- V89 regression kontrolü eklendi.
- V88 regression ve yayın kapısı V89 aday kontrolüne bağlandı.
- Kritik kaynak dosyaları için SHA-256 kaynak parmak izi üretimi eklendi.
- 1.0 adayının üretim doğrulaması yapılmadan “hazır” ilan edilmesini engelleyen açık durum kaydı oluşturuldu.
- Devir belgeleri V89 durumuna güncellendi.

## Sınırlar
Gerçek Cloudflare/D1/Worker/tarayıcı/push üretim doğrulaması bu çalışma ortamında yapılmadı ve V89 bunu başarılı gibi göstermemektedir.
