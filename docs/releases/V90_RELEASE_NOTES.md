# V91 Sürüm Notları

## Amaç

V91, ZATO Chess'in 1.0 öncesi üretim kanıtı ve teslim hazırlığı sürümüdür.

## Yapılanlar

- Üretim kanıtı manifestosu oluşturuldu.
- 1.0 yayın karar kapısı netleştirildi.
- Üretim ortamı doğrulaması ile kod hazırlığı ayrıştırıldı.
- V91 regression ve yayın kapısı betikleri eklendi.
- Devir belgeleri V91'a güncellendi.

## Bilinen durum

Gerçek Cloudflare/D1/tarayıcı üretim kanıtı bu çalışma ortamında mevcut değildir. Bu nedenle V91 kendisini üretimde doğrulanmış 1.0 olarak işaretlemez.
